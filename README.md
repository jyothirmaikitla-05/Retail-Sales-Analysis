# Retail Sales & Store Performance Analysis

## Project Overview
This project analyzes retail sales data using Python. The objective is to understand sales performance, customer behavior, profit trends, and regional performance through data analysis and visualization.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Dataset
- Superstore Dataset
- Records: 9,994
- Columns: 21

## Features
- Data Cleaning
- Basic Sales Analysis
- Category-wise Sales
- Region-wise Sales
- Top 10 States by Sales
- Monthly Sales Trend
- Top 10 Products
- Customer Segment Analysis
- Top 10 States by Profit
- Ship Mode Analysis
- Top 10 Customers
- Discount vs Profit Analysis
- Sales by Year
